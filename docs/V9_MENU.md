# Île Manga V9 — Menu fantasy

Mise à jour légère à appliquer sur le code V8 via `python3 pcvr/apply_v9.py` après extraction du ZIP. Elle embellit le panneau, le titre et les boutons du menu PC et indique la zone dans les six emplacements de sauvegarde. Les données des sauvegardes ne sont pas changées, ni les commandes VR. Le menu VR conserve son système de navigation et reçoit son titre V9.

Deux exécutables Windows seulement : Ile_Manga_VR_v9.exe et Ile_Manga_PC_v9.exe. Vérifier compilation GitHub et rendu dans le Quest 3.
