# Règle des quêtes (à respecter dans tous les textes)

Les quêtes du jeu sont des choses que le JOUEUR fera (ou a peut-être déjà faites) : les textes ne doivent
JAMAIS en donner l'issue. Rien ne dit qu'un objet perdu a été retrouvé, qu'un problème est réglé, qu'un
mystère est résolu — ni le contraire de façon définitive. Chaque phrase doit rester vraie AVANT comme APRÈS
la quête : on parle du problème comme d'un souci actuel ou d'un souvenir sans conclusion (« l'alliance qu'Hugo
a perdue dans le sable », « ce voleur de croissants », « l'horloge arrêtée »), jamais « retrouvée », « classée »,
« réparée », « attrapé ».

Quêtes du carnet (donneur : sujet) :

- odette : le registre du port (noms des bateaux de Fernand, Yannick, Lucas)
- margaux : livrer le pain du matin (Chez Paulo, Café de la Place, Grand Hôtel)
- django : la partition envolée (trois pages dispersées)
- theo : le cerf-volant envolé vers les collines de l'ouest
- lea : l'alliance perdue d'Hugo dans le sable, près du Coco Loco
- lefort : le voleur de croissants de Margaux (le chien)
- anselme : la lentille du phare (un morceau tombé dans la mer)
- kevin : le défi des trois étoiles de mer ; bernard : la course fontaine-phare
- clemence : les couleurs naturelles (corail, miel, noix de coco) ; paulo : la bouillabaisse (daurades, maquereaux)
- nadine : les cartes postales ; toni : les noix de coco du punch ; pemberton : une curiosité rare
- hortense : l'horloge arrêtée (un rouage qu'Hector doit forger)
- raymond : le cochonnet perdu ; gerard : l'appareil photo oublié au belvédère
- moreau : le secret de l'Atlantide
- matthias : la Porte aux Quatre Sceaux, la grande enquête des sceaux ; tobias : le bois pour la voie d'eau
- croc : la carte au trésor volée par un chat roux ; zohra : le tajine du vendredi (deux dorades)
- cogne : l'engrenage d'or tombé des falaises ; heloise : le jury de la Foire ; boum : le minerai pour le quinzième toit
- merelune : les lanternes de lune ; pepin : battre Bondi à la Grande Course ; bedaine : le Grand Troc
Et les petites quêtes de chaque fiche (« quete » dans les fichiers *_habitants_*.gd) : même règle.
